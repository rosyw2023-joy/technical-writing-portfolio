# Guest Check-In Guide

## Overview

The Guest Check-In feature allows hotel staff to register arriving guests, assign rooms, and complete the check-in process. Before checking in a guest, ensure that a confirmed reservation exists and the assigned room is ready for occupancy.

## Prerequisites

Before beginning the check-in process, ensure that:

* The guest has a confirmed reservation.
* The assigned room is available and has been cleaned.
* The guest provides a valid identification document.
* Any required deposit or payment has been received.

## Check-In Procedure

1. Log in to StaySync using your staff account.
2. From the dashboard, select **Reservations**.
3. Search for the guest using their name or reservation number.
4. Open the reservation details.
5. Verify the guest's identity using a valid identification document.
6. Confirm the assigned room and stay dates.
7. Record any required payment or security deposit.
8. Click **Check In** to complete the process.

## Expected Result

Once the check-in is completed:

* The guest's status changes to **Checked In**.
* The room status changes to **Occupied**.
* The reservation is updated automatically.

> **Note:** A guest cannot be checked in if the assigned room is marked as unavailable or under maintenance.

> **Tip:** Always verify the guest's identification before completing the check-in process to prevent booking errors and maintain accurate records.
